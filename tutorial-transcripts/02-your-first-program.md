# Video 02 — Your first program

| Field | Value |
| --- | --- |
| **Title** | Your first program in CodeDam |
| **Target length** | 75–90 seconds |
| **Goal** | Build and run a tiny program that shows a message |
| **Start URL** | `/playground` |
| **Demo result** | User Output shows a greeting (e.g. `Hello, Beavy!`) |
| **Tone** | Step-by-step, encouraging |

---

## Recording setup

- Fresh playground (empty canvas: “Drop planks here to build your dam!”)
- Desktop 1920×1080, zoom 100%
- Record silent; AI voice from narration below
- Move the cursor slowly; pause after each drop so viewers can follow

---

## What you will build

```
User Output
  └─ Use Value  →  text: "Hello, Beavy!"
```

Categories used: **Interactions**, **Variables**

---

## On-screen text (optional captions)

1. `Open the Workshop`
2. `Drop User Output on the dam`
3. `Add a value inside it`
4. `Hit Play`

## Shot list + narration

| Time | Action | Narration |
| --- | --- | --- |
| 0:00–0:08 | Show empty playground. Point left → Workshop, center → Build Your Dam, right → Code Preview + green Play. | This is the CodeDam playground. Blocks live in the Workshop on the left. You build in the middle. And on the right, you’ll see real code — plus Play to run your program. |

**Full narration (copy-paste for AI voice):**

> This is the CodeDam playground. Blocks live in the Workshop on the left. You build in the middle. And on the right, you’ll see real code — plus Play to run your program. Let’s make a program that says hello. Open Interactions, then drag User Output onto the dam. Now give it something to show. From Variables, drag Use Value into the empty slot. Set it to text: Hello, Beavy! Watch the Code Preview — CodeDam writes the matching JavaScript or Python as you build. Hit Play. Your program runs — and there’s your message. That’s your first CodeDam program. Nice work!
