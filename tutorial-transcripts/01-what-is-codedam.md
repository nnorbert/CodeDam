**Full narration (copy-paste for AI voice):**

> Hi! Welcome to CodeDam — a free visual coding playground for kids. Meet Beavy. Beavy’s here to help you learn coding the fun way — by snapping blocks together. Instead of typing tricky code first, you build programs with blocks — loops, variables, and logic — and learn the ideas behind real programming. Drag and drop so you don’t get stuck on typos. Run your program step by step. And watch real JavaScript or Python appear as you build. It works in your browser on a laptop or tablet. No downloads, and you don’t need an account to start. Ready? Click Start Building to open the playground. Grab blocks from the Workshop, drop them on the dam, and hit Play. Let’s build something cool.
