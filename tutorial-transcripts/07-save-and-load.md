# Video 07 — Save and load a project

| Field | Value |
| --- | --- |
| **Title** | Save & load your CodeDam project |
| **Target length** | 60–75 seconds |
| **Goal** | Show downloading a project and restoring it later |
| **Start URL** | `/playground` with a small finished program already on the canvas |
| **Demo result** | Canvas cleared (or new tab) → Load restores the same blocks |
| **Tone** | Practical; parents/teachers will care about this |

---

## Recording setup

- Prepare a small program before recording (e.g. the Hello / score demo from earlier videos)
- Execution must be **stopped** (Save/Load lock while running or paused)
- Desktop 1920×1080; know where your browser downloads files
- Silent capture + AI voice

---

## What you will demonstrate

1. Existing blocks on **Build Your Dam**
2. Click **Save** → name the project → download JSON
3. Clear the canvas *or* refresh / open a clean playground
4. Click **Load** → choose the file → blocks return

---

## On-screen text (optional captions)

1. `Save downloads your project`
2. `Load brings it back`
3. `Stop Play before Save or Load`

---

## Shot list + narration

| Time | Action | Narration |
| --- | --- | --- |
| 0:00–0:10 | Show a small finished program on the canvas. Point at **Save** / **Load** in the Build Your Dam header. | Built something cool? Don’t lose it. CodeDam lets you save and load projects from your device. |
| 0:10–0:25 | Ensure Play is stopped. Click **Save**. In the save modal, enter a clear name like `my-first-dam`. Confirm so the file downloads. | Make sure your program isn’t running. Click Save, give your project a name, and download the file. |
| 0:25–0:40 | Show the downloaded file briefly in the downloads bar or folder (optional). Then clear the canvas — e.g. refresh the page or remove blocks — so the dam looks empty. | The project is saved as a file on your computer. Here’s an empty playground — like starting fresh. |
| 0:40–0:55 | Click **Load**. Pick the saved file. Wait for restore. Zoom/pan so the restored blocks are obvious. | Click Load, choose that file, and your blocks come right back — ready to keep building. |
| 0:55–1:10 | Optional: hit **Play** once to prove it still works. End on CodeDam logo / header. | Run it again to check. Save often, share the file with a teacher or friend, and pick up right where you left off. |

**Full narration (copy-paste for AI voice):**

> Built something cool? Don’t lose it. CodeDam lets you save and load projects from your device. Make sure your program isn’t running. Click Save, give your project a name, and download the file. The project is saved as a file on your computer. Here’s an empty playground — like starting fresh. Click Load, choose that file, and your blocks come right back — ready to keep building. Run it again to check. Save often, share the file with a teacher or friend, and pick up right where you left off.
